## ✨ 주요 기능

### 1. 🔮 6가지 맞춤형 추천 알고리즘
- **🎲 완전 랜덤**: 1부터 45까지 균등 확률 무작위 추첨
- **🔥 최다 빈출 (HOT)**: 동행복권 역대 누적 1등 최다 출현 번호 통계 가중치 부여
- **❄️ 미출현 반등 (COLD)**: 최근 및 역대 미출현 번호들의 반등을 노리는 역발상 조합
- **⚖️ 황금 밸런스**: 1등 당첨 통계의 80% 이상을 차지하는 총합계(100~175)와 홀짝/고저 비율 필터링
- **🔮 꿈·소원 사주 해몽**: 오늘 꾼 꿈(돼지, 용, 물, 불 등)이나 소원을 입력하면 해시 알고리즘을 통한 맞춤 번호 및 AI 길조 해몽 메시지 제공
- **🎯 고정수 & 제외수 필터**: 1~45 번호판에서 클릭으로 포함할 고정수(최대 5개, 녹색) 및 제외수(빨간색 취소선) 직접 지정

### 2. 🎰 실시간 3D 물리 추첨기 시뮬레이션 (Canvas)
- 유리 구체 내부에서 45개의 미니 볼이 중력과 반발력에 따라 실시간으로 바운스되는 2D 물리 엔진 구현
- 번호 추첨 시 회오리 바람을 모사한 고속 터보 스핀 가동
- 마우스 및 터치 제스처로 내부 볼들을 직접 튕겨볼 수 있는 인터랙티브 기능 탑재

### 3. 🌓 다크 모드 & 화이트(라이트) 모드 테마 지원
- 헤더의 테마 전환 버튼(🌙/☀️)을 통해 고급스러운 다크 모드와 산뜻한 화이트 모드를 원클릭으로 전환
- 사용자 테마 설정은 `localStorage`에 자동 보관되어 재방문 시에도 유지

### 4. 🔊 순수 Web Audio API 사운드 신시사이저
- 외부 음원 파일 종속성 0%! 브라우저 자체 오디오 API로 구동
- 볼 굴러가는 소리, 공이 뽑힐 때의 펜타토닉 음계 차임벨, 추첨 완료 팡파르 합성음 구현
- 헤더의 사운드 버튼(🔊/🔇)으로 자유롭게 음소거 토글 가능 (설정 영구 저장)

### 5. 📊 스마트 패턴 분석 및 편의 기능
- 각 게임별 **총합계**, **홀짝 비율**, **고저 비율**, **연속 번호** 자동 분석 배지
- 단일 게임 및 전체 5게임 원클릭 클립보드 복사
- **🧾 로또 복권 영수증 이미지 다운로드**: HTML5 Canvas를 활용하여 실제 복권 용지 스타일의 고화질 PNG 이미지 즉시 생성
- **🏆 가상 당첨 시뮬레이터**: 이번 주 가상 1등 번호(+보너스)를 뽑아 내 번호와 실시간 일치 대조 및 등수(1~5등) 판정 리포트
- **⭐ 내 번호 보관함**: 마음에 드는 조합을 로컬 스토리지에 저장하고 언제든 열람/삭제 가능
- **🎉 축하 컨페티 폭죽**: 추첨 완료 시 화면 전체에 화려한 파티클 폭죽 애니메이션 발사

### 6. 🤝 Formspree 기반 비즈니스 & 제휴 문의 폼
- **Formspree(`https://formspree.io/f/mqppdbpl`) 연동**: 별도의 서버 없이 안전하고 빠른 이메일 알림 전송
- **AJAX 비동기 폼 제출**: 페이지 새로고침 없이 즉각적인 전송 상태 및 피드백 메시지 제공
- **스팸 방지 봇 필터(Honeypot)** 및 개인정보 수집 동의 유효성 검증
- 헤더 및 푸터의 원클릭 스크롤 내비게이션 지원

## 🚀 실행 방법

외부 패키지나 빌드 과정 없이 순수 HTML/CSS/JavaScript로 구현되어 있습니다.

1. 본 저장소를 클론합니다:
   ```bash
   git clone https://github.com/qkrguwh123-ops/product-bulider-lecture.git
   ```
2. `index.html` 파일을 웹 브라우저에서 직접 더블 클릭하여 실행하거나, 로컬 웹 서버(Live Server 등)를 통해 열어보실 수 있습니다.
